# 个人功能使用说明：反馈、画像、回忆与周报

这些功能只对机器人所有者开放：命令只有管理员能在客户端看到，别人即使调用也会被拒绝，
回复都是私密的。个人推送和周报都发到收件箱频道（`/set_inbox_channel` 设置）。

## 1. 给推送表态

个人推送（`following`）每条下面有一排按钮：

| 按钮 | 含义 |
|---|---|
| 🆕 | 新知：之前不知道、值得知道 |
| 👌 | 已知：早就知道了 |
| 🚫 | 不关心：跟我无关 |
| 📥 | 存进收件箱，稍后细看 |

- 再点一次同一个按钮就是撤销；选中的按钮会变绿。
- 在任何 bot 消息（包括共享频道的卡片）上加 🆕 / 👌 / 🚫 反应也算数。一条消息只有一条内容时，
  反应等于按按钮；一条消息有 n 条内容时，每条记 1/n 的"粗反馈"，粗反馈不会覆盖按钮。
  移除反应就撤销这条反应。
- 共享频道的内容和选编不受你的反馈影响，反馈只用于你自己的个人推送和统计。

## 2. 画像怎么用

近 90 天的反馈会算成一份"读者画像"（越近权重越大，半衰期 30 天）：哪些来源、板块、话题
常给你新知，哪些多半是已知或不关心。个人推送选编时会参考它，让推送更偏向"你不知道、但该知道"。

- 精确反馈（按钮，或单条消息上的反应）满 15 条之前是冷启动，不使用画像。
- `/feedback_stats days by`：看最近 7–365 天（默认 30）按来源、板块或标签的曝光数、已评数、
  🆕/👌/🚫 和新知率，每行附当前的选编权重；最后附上当前发给模型的画像片段。

## 3. `/recall`：从自己的收藏和新闻存档里回忆

```
/recall question:<问题> scope:<全部|新闻|收藏> days:<7–365，默认 90>
```

- 在本地知识库（收件箱里存过的内容，加上近 90 天出现过的新闻；推送过、反馈过或收藏过的新闻
  保留 365 天）里检索，再让模型只依据检索到的材料作答，句子后面的 `[S1]` 对应末尾的来源链接。
  没有原文链接的收藏会链到当时保存的那条消息。
- 本地没有相关记录时直接告诉你，不调模型；作答模型失败时列出命中的前几条材料。
- 一次只处理一个 `/recall`，后来的会排队；每天有调用次数上限。
- 知识库每 30 分钟从新闻素材池和收件箱同步一次，刚存的内容最多半小时后才能检索到。

## 4. 每周回看（周报）

每周一 09:00 自动把上一周（周一到周日）的回看发到收件箱频道，只发一次；机器人当时不在线
就跳过，不补发。内容全部是统计，不调模型：

1. 推送曝光：个人和共享各多少条；
2. 🆕 / 👌 / 🚫：按钮这类精确反馈与反应的粗反馈分开列，再给合计和新知率，以及近 4 周的新知率走势；
3. 来源：🆕 最多的前 5 个来源；本周有曝光但一条 🆕 都没有的来源；**砍源候选**（本周曝光 ≥ 3 次
   且零 🆕）；本周没被推送过的个人源；本周没有新素材的信源（可能失效）；以及各板块一行；
4. 收件箱：本周存入、读完、丢弃各多少，现在还积压多少、最老的放了几天；
5. 主题追踪的命中（还没有启用时显示"暂无"）；
6. 本周用了几次 `/recall`；
7. 当前画像摘要（冷启动时显示还差几条精确反馈）。

砍源只是建议，机器人不会自己改信源；确认要砍就用 `/source_remove`。

`/review week:<YYYY-Www>` 可以随时私密查看任意一周（默认上一周，例如 `2026-W41`），不影响
定时周报。
